# 2. Unified Security Finding Register (`UNIFIED_SECURITY_FINDINGS.md`)

This canonical register consolidates all findings from `adversarial_trust_boundary_audit.md` (`EV-05`), `hostile_security_audit_review.md` (`EV-06`), historical Wave 1/1.5 audits (`EV-01`..`EV-04`), and our independent codebase sweep. Every finding is mapped to its verified status, exact file/line evidence, and root-cause family (`RC-01` through `RC-06`).

---

## 1. Root-Cause Family Taxonomy

- **RC-01 (Principal, Session, Machine, & Entitlement Binding)**: Disjoint authentication paths (`operator-auth.mjs` vs `envelope-validator.mjs`), missing `req.accountId` invariant checks, permissive account/machine state checks, optional `clientGeneration` headers, and missing license expiry / seat-limit enforcement on domain mutations.
- **RC-02 (Payment Verification, Multi-Alias Replay, & Webhook Integrity)**: Uncoordinated payment redemption across `billing.mjs`, `outbox/worker.mjs`, and `billing/service.mjs`, allowing cross-account reference theft, `tx_ref` vs `id` dual-redemption, arbitrary `planId` price mismatches, and unverified webhook `charge.failed` email targeting.
- **RC-03 (Multi-Tenant Data, Config, & Broadcast Isolation)**: Shared singleton `global_automation_configs WHERE id = 'primary'` across all tenants, operator-accessible global catalog/channel mutations (`platforms.mjs`, `support.mjs`), fail-open WebSocket broadcast when `targetAccountId` is omitted, and cross-tenant session revocation in `machine/repository.mjs`.
- **RC-04 (Machine Identity, Reconciliation, & Revocation Completeness)**: Machine re-registration returning before `selfSignature` verification, `/reconcile` trusting unverified `envelope.machineId`, `LICENSE`-scope revocation leaving sessions active, and local storage `uploadId` path traversal.
- **RC-05 (Operator & Admin Authentication Hardening)**: Schema column mismatch (`password_hash` vs `credentials_hash`), unverified MFA disablement in `CONFIGURE_MFA`, missing `/auth` and `/admin/login` rate limiters, and admin TOTP replay / timing oracle gaps.
- **RC-06 (Control Plane Local Credential Protection at Rest)**: Plaintext bookmaker passwords stored in SQLite `accounts_metadata_cache.account_password` instead of AEAD-encrypted ciphertext.
