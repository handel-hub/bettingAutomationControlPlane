## 1. Adversarial Invariant Test Matrix

All root-cause fixes are verified by automated adversarial tests in [`bettingAutomationBackend/tests/security-redesign-invariants.test.mjs`](file:///c:/Users/John/Documents/CODE/back/bettingAutomationBackend/tests/security-redesign-invariants.test.mjs) and Control Plane test suites (`npm test`, `npm run test:statestore`, `npm run test:boundary`, `npm run test:adversarial`):

| Test ID | Root Cause / Finding Covered | Adversarial Scenario Tested | Expected Security Outcome |
|---|---|---|---|
| **SEC-INV-01** | `RC-01` / `USF-01` | Attacker sends valid v2 signed envelope with `sessionId: null` to an `operatorAuth`-protected `/api/v1/*` route. | Rejected with `401 Unauthorized` (`SESSION_REQUIRED` / `Session required for operator endpoints`). |
| **SEC-INV-02** | `RC-01` / `USF-07`, `USF-08` | (a) Envelope sent with expired session or `SUSPENDED` account; (b) Authenticated envelope sent without `clientGeneration`; (c) `POST /sessions/renew` called on an expired session. | All rejected (`401` / `400 MISSING_CLIENT_GENERATION` / `403 Session expired or not authenticated`). |
| **SEC-INV-03** | `RC-02` / `USF-02`, `USF-03` | (a) Replay same payment reference twice on `/api/v1/billing/payments/verify`; (b) Redeem via webhook (`tx_ref`) then replay via `/verify` (`id` alias); (c) Verify Paystack `'success'` status in Kobo minor units; (d) Pass unknown `planId` or underpaid amount. | First valid redemption succeeds; any replay across `tx_ref` or `id` fails with `409 PAYMENT_ALREADY_REDEEMED`; unknown plan / underpaid amount rejected with `400`. |
| **SEC-INV-04** | `RC-03` / `USF-04`, `USF-05` | (a) Tenant A calls `PATCH /api/v1/automation/global/risk`, then Tenant B calls `GET /api/v1/automation`; (b) Operator calls `POST /api/v1/platforms`, `PATCH /api/v1/platforms/:id/status`, or `POST /api/v1/support/channels`. | (a) Tenant A's mutation is isolated to `id = tenantA` and never alters `'primary'` or Tenant B's snapshot; (b) Operator calls to admin catalog/channel endpoints fail with `401/403`. |
| **SEC-INV-05** | `RC-03` / `USF-06`, `USF-12` | (a) `broadcast()` invoked with `targetAccountId = null`; (b) Session/Account revoked while WebSocket is open; (c) Tenant A attempts to revoke Tenant B's machine. | (a) Zero messages delivered when `targetAccountId` is missing; (b) Matching WebSocket is immediately closed (`4003`); (c) Cross-tenant `revokeMachine` leaves Tenant B's machine and sessions untouched. |
| **SEC-INV-06** | `RC-04` / `USF-10` | (a) Re-register existing `machineId` with invalid `selfSignature`; (b) Call `/reconcile` with mismatched `envelope.machineId`; (c) Revoke `LICENSE` scope for session with `license_id = NULL`; (d) Pass `../../evil` as `uploadId` to `StorageAdapter.uploadLocal`. | (a) Rejected before returning existing machine; (b) Reconciles only verified `req.machineId`; (c) All account sessions revoked and `session_generation` incremented; (d) Path traversal stripped via `path.basename`. |
| **SEC-INV-07** | `RC-05` / `USF-11` | (a) Operator `REGISTER`, `VERIFY_PASSWORD`, `CHANGE_PASSWORD` using `credentials_hash`; (b) Disable MFA without `stepUpToken`; (c) Replay same Admin TOTP code within 30s window. | (a) Succeeds against `credentials_hash`; (b) Rejected without step-up verification; (c) Second admin login with same TOTP step rejected. |
| **SEC-INV-08** | `RC-06` / `USF-13` | Create betting account with password in CP `AccountsAdapter`, inspect raw SQLite column `accounts_metadata_cache.account_password`, and call `getRawPassword()` + `listByUser()`. | Raw SQLite column starts with `enc:v1:` (never plaintext), `getRawPassword()` returns decrypted password for `VaultCredentialPipeline`, and `listByUser()` returns `'[PROTECTED]'`. |
